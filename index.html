      pocket controls
      
        
      These are the current rules. The toolbar stays quiet; row actions live on right-click / .; Ctrl/Cmd+F wakes the filter
      
        
      
          
      +add a new item below the selected item
      
          
      Entercopy in copy branches; otherwise edit details
      
          
      Double-clickedit details, including in copy branches
      
          
      Arrow keysmove through the tree; in Move mode, move the item
      
          
      Spacefold or unfold children
      
          
      Escclose, clear, or return to the tree
      
          
      Right-click / .open row actions, including Edit and Delete
      
          
      Ctrl/Cmd + Ssave the active Pocket file or encrypted Vault
