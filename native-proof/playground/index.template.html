What this proves: Actual core edit, revision, dirty-state and baseline-confirmation calls can run in a browser, with no server connection. The baseline is not a disk Save. Returning to identical baseline text now correctly returns Pocket to a clean state, even though its revision history continues to advance. All content disappears on reload.
